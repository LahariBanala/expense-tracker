# Expense Tracker

A simple and user-friendly web application to track daily expenses.

## Features

- Add expenses
- View expense list
- Calculate total expenses automatically
- Filter expenses by category
- Delete expenses
- Save data using Local Storage
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Categories

- Food
- Travel
- Shopping
- Education
- Other

## Project Purpose

This project was developed as part of a Mobile App Development learning module to understand app logic, local data, JSON, and device storage concepts.
